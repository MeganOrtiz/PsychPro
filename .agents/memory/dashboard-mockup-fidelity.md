---
name: Dashboard artwork mockup fidelity
description: Preserve actual dashboard structure when comparing decorative artwork
---
For artwork-only dashboard mockups, do not accept reconstructed generic dashboards as faithful previews. Use actual source extraction or clearly labeled image composites of the owner's screenshots.

**Why:** source-guided reconstruction repeatedly changed sidebar navigation, wordmark typography, colors, and cards despite an artwork-only brief. EPPP has its own shell; it must not inherit the main dashboard navigation.

**How to apply:** visually compare results against actual source/screenshots before presenting. If using uploaded screenshots, inspect their native dimensions before applying coordinates from chat thumbnails. Static image mockups are visual concepts, not verified live-page implementations.
