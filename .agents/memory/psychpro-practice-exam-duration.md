---
name: Practice exam duration
description: Owner's fixed 15-minute total budget for topic practice exams.
---

All standard practice exams should have a 15-minute total countdown, not a
per-question budget. This applies to main-site and EPPP topic practice exams
and timed custom-deck practice exams.

**Why:** The owner saw a topic exam start around 45 seconds and requested
“15 minutes for all practice exams.”

**How to apply:** Standardize topic timing at the API boundary so web and mobile
agree despite old saved durations. Full-length EPPP sittings share the topic
exam endpoint/storage but are not standard practice exams; preserve their
longer budgets. Course mastery exams are also a separate exam type.
